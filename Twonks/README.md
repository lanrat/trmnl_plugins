# [Twonks](https://trmnl.com/recipes/272414?ref=mrlanrat)

Displays [Twonks](https://www.twonks.co.uk/) comics by Steve Nelson on your TRMNL device.

![Screenshot](screenshot.png)

## Description

This plugin fetches and displays the latest Twonks comic strip.

Comics come from the artist's Bluesky account ([@twonks.bsky.social](https://bsky.app/profile/twonks.bsky.social)) via the public AppView API.

## Settings

No custom settings required.
